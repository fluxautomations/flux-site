01
Invoice captureOCRTallyRuns on your server

Invoice capture engine

The problem

Processing vendor invoices from WhatsApp, Telegram or email meant opening PDFs, reading unstructured formats, and typing data into an Excel log by hand.

The solution

Forward the image or PDF and within seconds it pulls out vendor, date, GST amount, category and total, logs the line into a master sheet, and posts the entry to the ERP on command.

The handover

Documentation, operator training and certification, full source code. Runs entirely on the client’s own hardware.

Guaranteed in writing
02
Accounts PayableBank IntegrationStreamlit AppRuns on your server

Payouts dashboard, from bill to bank file

The problem

Managing vendor payouts meant checking Tally for outstanding bills, formatting bank upload files (NEFT/RTGS), and manually emailing payment advice to every vendor.

The solution

A secure web dashboard running inside the client’s network. It takes the payout inputs, fuzzy-matches them to the right vendor, and allocates against outstanding bills FIFO. From there it writes the transaction back to the ERP, produces the bank-ready file, and sends the advice emails in one go.

The handover

Deployed inside the client’s network. No payout data leaves the premises. Documentation, training and source code handed over.

Guaranteed in writing

04
Accounts ReceivableTally XMLOutlook

Intelligent AR & follow-up engine

The problem

Someone had to track which bills were aging, tie them back to the client ledger, then write the follow-up emails one at a time. It took hours, and the ones that got missed were the ones nobody noticed.

The solution

A pipeline that reads live Bills Receivable data out of Tally and sorts it into aging buckets. It builds an interactive Excel dashboard with forecast charts, then sends personalised follow-ups through Outlook.

The handover

Runs on the client’s machine on a schedule. Documented, trained, owned by the client.

Guaranteed in writing
05
Browser AutomationsPlaywrightNo API Needed

Browser automation without API access

The problem

Government sites, vendor portals, legacy ERP interfaces. A lot of them offer no API at all, so the work got done manually, browser tab by browser tab.

The solution

With Playwright and Selenium we automate the browser itself: logging in, moving through pages, filling forms, clicking buttons, reading the data off the screen the way a person would, except on a schedule and without anyone sitting there. If it can be done in a browser, it can usually be automated.

The handover

Scripts, credentials handling and documentation stay on the client’s own machine.

Guaranteed in writing
